# Forever Gear Guide

A pre-raid guide for World of Warcraft Forever. Compare your gear with Full and Realistic BiS lists, find dungeon and quest upgrades, and check enchants, recipes, and material prices.

## Install with WowUp

1. Select your WoW Forever installation in [WowUp](https://wowup.io/).
2. In **Get Addons**, choose **Install from URL** and enter https://github.com/ovallsn/wow-forever-gear-guide.
3. In **My Addons**, right-click **Forever Gear Guide** and turn on **Auto Update**.

Open the guide from the in-game minimap or use **/fgg**. If the game was already open when WowUp updated the addon, use **/reload**.

[Download the latest ZIP](https://github.com/ovallsn/wow-forever-gear-guide/releases/latest) to install manually. The ZIP contains the addon, data source credits, and third-party license notices.
